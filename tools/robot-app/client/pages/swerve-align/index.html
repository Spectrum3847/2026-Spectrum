1 Pin the modules straight

This drivetrain is not a rectangle — the rear modules sit on the angled plates of a hexagonal frame, so there is no pair of wheels you can lay a straight edge across. Use each MK5n module’s own alignment pin instead: it references the module to itself and does not care what the frame looks like.

Tick each item as you do it. None of these are checked by software — they are the part only you can verify.
